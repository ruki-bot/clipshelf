# クリップ棚（ClipShelf）

Mac用のクリップボード履歴アプリの配布ページです。最新版は右の「Releases」の ClipShelf.zip です。

```
クリップ棚（ClipShelf）の使い方メモ

■ はじめに
コピーしたものの履歴をためて、呼び出して貼れるMac用のアプリです。
履歴や設定はすべてあなたのMacの中だけに保存されます。何も入っていない状態で配っています。

■ 1. 開き方（最初の1回だけ）
Appleの正式な署名がないため、ダブルクリックだと「開けません」と出ます。
次のどちらかで開いてください。
 (A) 「クリップ棚.app」を「アプリケーション」フォルダに入れ、右クリック →「開く」→ もう一度「開く」
 (B) 一度ダブルクリックして警告が出たら、システム設定 →「プライバシーとセキュリティ」→ 下の方の「このまま開く」

■ 2. アクセシビリティの許可
貼り付けを自動で行うために必要です。
システム設定 →「プライバシーとセキュリティ」→「アクセシビリティ」→ クリップ棚をオンにしてください。
オンにしたのに動かないときは、一度オフ→オンにして、アプリを開き直してください。

■ 3. 呼び出しキー
 ・クリップ棚を開く：⌘ + ⇧ + V
 ・スタック（続けて貼る）：⌘ + ⇧ + C
Paste（アプリ）が入っていると、同じキーがぶつかることがあります。
その場合は、クリップ棚の「設定」→「ショートカット」で別のキーに変えてください。
（または Paste 側のキーを変えるか、Paste を終了してください）

■ 4. 自動アップデート
新しい版が出ると、起動時と数時間おきに自動で確認して、確認画面なしで入れ替わり、アプリが自動で開き直します。
履歴や設定はそのまま残ります。
入れ替わったあと、アクセシビリティの許可が外れることがあります。そのときは「2.」をもう一度行ってください。
「アプリケーション」フォルダなど、自分で書き込める場所に置いたときだけ自動で更新されます。

■ 5. URLパラメータ（任意）
リンクのカードを選んで ⌥ + Return、または右クリック →「貼り方を選ぶ」で、媒体ごとの規則でURLパラメータ付きで貼れます。
規則は、データフォルダ（~/Library/Application Support/ClipShelf）の url-params.json を編集して自分用に変えられます。
最初は例が1つだけ入っています。使わなければ何も起きません。
※今の版でURLパラメータが付くのは、LIDNM・Llife のリンクだけです（ZOZOはBitly短縮）。それ以外のサイトのリンクは、そのまま貼られます。

■ 6. Bitly（任意）
ZOZOのリンクを短縮したい人だけ使います。自分のBitlyのトークンが必要です。
設定 →「URL パラメータ」にトークンを入力して保存し、「Bitly で短縮する」をオンにしてください。
トークンはあなたのMacのキーチェーンにだけ保存されます（他の人には共有されません）。
入れなければ、Bitlyとは通信しません。

■ 困ったとき
・メニューバーにアイコンが出ない／動かない：アプリを終了して開き直す
```
